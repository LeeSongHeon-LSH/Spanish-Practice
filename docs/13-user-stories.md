## 13. 유저 스토리 — 확정 (2026-08-14)

§12의 FR/SEC를 **사용자 관점 스토리**로 재서술한 것. 액터는 **본인 1인**(§9.3 1계정 전제)이라 페르소나 구분이 없다. 우선순위 [C]/[P]는 §12.1과 동일. 세부 규칙의 원본은 "추적" 열의 FR/§ — 스토리와 명세가 어긋나면 **§12이 이긴다**.
